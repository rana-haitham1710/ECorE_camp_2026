# ECorE Network Track - Camp Documentation

Welcome to the official repository for the Networking Track in **ECore Camp**, organized by the Electronics and Communications Engineering (ECE) department team at Mansoura University. 

This repository contains my contributions as a **Network Instructor** for Sessions 5 and 6, along with the comprehensive materials, guides, and the final project.

---

##  Instructor Role & Contributions
* **Track:** Networking
* **Position:** Network Camp Instructor (Sessions 5 & 6)
* **Key Responsibilities:**
  * Prepared and delivered advanced networking and routing sessions.
  * Designed interactive quizzes during the sessions to boost engagement and knowledge retention.
  * Conceived, designed, and supervised the **Final Project**, integrating core concepts learned throughout the camp into a robust multi-branch network topology.

---

##  Repository Contents & Overview

### 1.  Session Presentations & Materials
* **`Routing.pptx` (Session 5):**
  * Router basics, hardware components, and modes.
  * Static and Dynamic Routing protocols (**RIP, EIGRP, OSPF**).
  * Access Control Lists (**ACLs**) - Standard and Extended.
  * Layer 2 Security & Switching concepts: **PortFast**, **Port Security**, **DHCP Snooping**, and **EtherChannel**.
  * *Interactive feature:* Included 2 interactive quizzes (one mid-session and one at the end).

* **`Session 6.pptx` (Session 6):**
  * **DHCP** configuration on both Routers and Windows Servers (DORA process).
  * **DNS** architecture and resolution paths.
  * **IPv6** concepts, structure, and notation rules.
  * **NAT** (Network Address Translation) types: Static NAT, Dynamic NAT, and PAT (NAT Overload).
  * *Interactive feature:* Included an interactive review quiz at the end of the session.

### 2.  Final Project & Documentation
* **`Topology_of_final_project.png`:** Visual diagram of the comprehensive enterprise network topology.
* **`Final_Project_Details.docx`:** Full project scope, objectives, and requirements covering inter-VLAN routing, NAT, DHCP, and security.
* **`Final_project_config.docx`:** Step-by-step configuration commands and implementation guide.
* **`Cisco_Router_Commands_Guide.docx`:** Handy reference guide for essential Cisco IOS commands.
